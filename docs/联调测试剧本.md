## 0. 前置准备（一次性）

1. **安装扩展**（普通终端，非受限沙箱）：

   ```powershell
   code --install-extension "D:\working\projects\dsh-vscode-agent\dsh-vscode-agent-0.1.0.vsix"
   ```

2. **确认配置**（全部默认即可）：`dsh.port=3080`、`dsh.channel=latest`、`dsh.command=""`、
   `dsh.autoStart=true`、`dsh.autoOpenPanel=true`、`dsh.dshHome=""`（与浏览器版共享会话）。

3. **清理残留状态**（确认无 VSCode 窗口在跑）：

   ```powershell
   del "$env:LOCALAPPDATA\DshVscode\instance.json" 2>$null
   del "$env:LOCALAPPDATA\DshVscode\startup.lock" 2>$null
   ```

4. **环境自检**：`node -v`（≥20）、`dsh --version`（本机 0.1.1-rc.2）、`code --version`（1.134.0）。

**通用取证命令**（任意场景随时可用）：

```powershell
# 注册表（谁拥有 dsh、哪些窗口挂载）
Get-Content "$env:LOCALAPPDATA\DshVscode\instance.json"
# dsh 子进程日志
Get-Content "$env:LOCALAPPDATA\DshVscode\logs\dsh.log" -Tail 100
# 端口监听者
netstat -ano | findstr ":3080"
# 某 pid 的进程/命令行
tasklist /FI "PID eq <pid>"
(Get-CimInstance Win32_Process -Filter "ProcessId = <pid>").CommandLine
```

**本机判定提示**：本机 dsh 由 npx 缓存托管，`@deepseek-ai/dsh` 的 bin 为 `lib/bin.js`，
故外部实例的 node 命令行形如 `node …\@deepseek-ai\dsh\lib\bin.js web …`，
**会命中** `looksLikeDsh` 的 `dsh[\/]lib[\/]bin.(js|mjs)` 正则 → pid 接管预期可成功。

| A1 | 普通终端执行 `dsh web`（默认监听 3080，形成外部实例） | 终端打印 `dsh web: http://127.0.0.1:3080` | — |

### D4 RW-2 端口 holder 身份核验（沙箱 SKIP 的真机兜底）
